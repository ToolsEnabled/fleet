# Fleet V5

Fleet V5 is a local orchestration runtime for coordinating coding-agent workers, tasks, and tools. This export is based on Fleet V5 5.0.0-alpha.13.

## Install

Requires Node.js 22.19 or newer. From this checkout, install the locked dependencies with `npm ci`, then install the command line package with `npm install --global .`. Run `fleetV5 --help` to see the command options. The `docs/` directory contains setup and migration guides.

The repository includes source and tests; machine-specific state and qualification evidence are not part of this export.
